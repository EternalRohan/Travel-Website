# Wego-Inspired Travel Website

A clean, modern travel website inspired by Wego’s style. Features a homepage with popular destinations, top deals, a stylish search bar, and an elegant footer. Fully mobile-responsive and lightweight.

## Features
- Stylish search bar (design only)
- 3–4 popular travel destinations in cards
- "Top Deals" section with 2–3 offers
- Elegant footer with About, Contact, and Newsletter
- Light, bright color scheme
- Fully responsive and interactive hover effects

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm start
   ```
